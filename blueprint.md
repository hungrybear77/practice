# Lotto Number Generator

## Overview

This is a simple web application that generates random lottery numbers. Users can click a button to get a set of 6 unique numbers between 1 and 45.

## Features

*   Generate 6 unique random numbers.
*   Display the generated numbers to the user.
*   Modern and clean user interface.
